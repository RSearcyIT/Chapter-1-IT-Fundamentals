## Definition of IT

IT is the use of computers, software, networks, data and digital systems to create, process, store, secure and exchange information. 
## Four Components of IT

- **Hardware** - consists of the physical components of a computer or device that can be touched.
- **Software** - consists of the programs and operating systems that run on the hardware and tell it what to do.
- **Networks** - a group of connected devices that communicate. 
- **Data** - information that is stored and processed electronically.
